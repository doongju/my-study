1. 관계형 데이터베이스 
데이터를 행과 열로 구성된 2차원 테이블형태로 관리하며, 테이블 간의 관계를 정의하여 데이터를 조직화
스키마 고정: 데이터를 저장하기 전에 테이블의 구조(열의 이름, 데이터 타입 등)를 엄격하게 미리 정의해야 한다.
2. NoSQL
다양한 데이터 모델을 사용하여 유연하게 데이터를 저장하는 데이터베이스
유연한 스키마: 데이터 구조를 미리 정의하지 않고도 자유롭게 행마다 다른 형태의 데이터를 넣을 수 있다

차이점 
데이터 구조에서 관계형 데이터 베이스는 2차원 테이블 구조이고 nosql은 유연한 구조다 또한 관계형은 고정된 스키마이고 no sql은 동적 스키마이다
